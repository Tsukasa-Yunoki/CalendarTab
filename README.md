## 特徴
- **2列表示対応**: 予定が多い時でも自動で左右2列に分割して表示。
- **重要単語ハイライト**: 設定したワード（例: 「!」）が含まれる予定を自動で赤色（カスタム可能）に変更。
- **概要欄（ティッカー）**: 特定のカレンダー（ゴミ出し、給食、テレビ番組など）を画面下部に横スクロールで表示。
- **自動文字サイズ調整**: 予定の数に合わせて、見やすい最適なサイズに自動調整。
- **フルカスタマイズ**: 設定メニューから、文字色、背景色、重要ワード、レイアウト比率を自由に変更可能。
- **自動同期リクエスト**: アプリ側からシステムに同期を促すため、予定の追加がリアルタイムに反映されやすい。

## 使い方
1. アプリを起動し、カレンダーへのアクセス権限を許可します。
2. 画面右上の「Update」エリアを **3回連続でタップ** すると設定メニューが開きます。
3. 「カレンダー選択」から、メインに表示するものと、概要欄に表示するものをそれぞれ選びます。
4. 必要に応じて「重要ワード・色設定」から自分好みにカスタマイズしてください。
   

## 再生中表示 (Now Playing バー)
Ubuntu側デーモン `server/nowplaying_daemon.py` が、Bluetooth再生中の曲を端末のメディアセッションから読み取り、NetEase APIで歌詞(LRC)を取得し、adbブロードキャストでアプリ上部のバーへ送ります。

- 1行目: ♪ 曲名 / アーティスト (マーキー)
- 2行目: 歌詞の現在行
- 停止時はバーが消え、カレンダーが全画面に戻ります

デーモンは systemd ユーザーユニット `server/echo-nowplaying.service` として常駐します。要: adb接続済みの端末、ローカルのNetEase APIコンテナ (127.0.0.1:3000) とCookieファイル。

### 補足 (改版について)
- パッケージ名は `my.app.calendarkiosk.roze` に変更し、初期リリース版と別アプリとして共存できるようにしました。表示名は「CalendarKiosk改」です。
- 再生中バーの文字サイズは、設定 → 文字サイズ設定 →「再生中バー：曲名サイズ / 歌詞サイズ」から変更できます。表示ON/OFFはレイアウト設定内にあります。
- バーに背景色は付けず、本体と同じ黒に同化させています。長い歌詞行は自動で縮小して全体を表示します。
