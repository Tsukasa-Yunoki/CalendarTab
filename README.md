## 特徴
- **2列表示対応**: 予定が多い時でも自動で左右2列に分割して表示。
- **重要単語ハイライト**: 設定したワード（例: 「!」）が含まれる予定を自動で赤色（カスタム可能）に変更。
- **概要欄（ティッカー）**: 特定のカレンダー（ゴミ出し、給食、テレビ番組など）を画面下部に横スクロールで表示。
- **自動文字サイズ調整**: 予定の数に合わせて、見やすい最適なサイズに自動調整。
- **フルカスタマイズ**: 設定メニューから、文字色、背景色、重要ワード、レイアウト比率を自由に変更可能。
- **自動同期リクエスト**: アプリ側からシステムに同期を促すため、予定の追加がリアルタイムに反映されやすい。

## 使い方
1. アプリを起動し、カレンダーへのアクセス権限を許可します。
2. 画面右上の「Update」エリアを **3回連続でタップ** すると設定メニューが開きます。
3. 「カレンダー選択」から、メインに表示するものと、概要欄に表示するものをそれぞれ選びます。
4. 必要に応じて「重要ワード・色設定」から自分好みにカスタマイズしてください。
